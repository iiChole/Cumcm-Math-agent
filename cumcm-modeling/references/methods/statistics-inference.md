# 统计推断与抽样决策

适用于抽样检验、质量判定、比例估计、实验数据分析和带不确定性的参数推断。题号不决定是否使用本方法。

## 先识别数据生成机制

- 有限总体、不放回抽样：优先考虑超几何分布或精确检验。
- 总体足够大、近似独立抽样：可考虑二项分布；使用正态近似前检查样本量和比例条件。
- 多因素观测或实验：考虑回归、方差分析或稳健回归，并解释参数意义。
- 小样本或稀有事件：优先精确方法、Bootstrap 或 Beta-Binomial，不要无条件套用正态近似。

## 基础模型

设总体规模为 (N)，其中不合格品数为 (D)，不放回抽取 (n) 件，不合格数为 (X)，则

\[
P(X=x)=\frac{\binom{D}{x}\binom{N-D}{n-x}}{\binom{N}{n}}.
\]

当抽样近似独立且总体不受抽样影响时，若不合格率为 (p)，可用

\[
X\sim\operatorname{Binomial}(n,p).
\]

必须说明采用哪一种分布及其近似条件。估计比例时给出点估计与区间，而不是只报告一个比例。

## 检验与可执行规则

把统计结论转化为行动规则：

1. 明确原假设、备择假设、容许质量水平和风险水平；
2. 指定抽样量、统计量和临界域；
3. 给出“接收/拒收”“继续/停止”或对应决策；
4. 计算第一类、第二类错误或 OC 曲线，说明规则在不同真实参数下的行为。

不要只写“采用二项检验”，而要给出抽多少、观察到多少时采取什么行动。

## 验证与扩展

- 精确概率与 Monte Carlo 交叉核对；
- 检查有限总体修正、边界比例和极端样本；
- 评估先验、过度离散、抽样偏差和测量误差；
- 若参数区间会改变最终方案，把区间传播到成本、收益或风险决策中；
- 序贯抽样、Bayes 或 Beta-Binomial 只有在数据机制确实需要时再引入。

## 常见误用

- 有限总体不放回抽样却直接使用独立二项模型；
- 小样本无条件使用正态近似；
- 把相关性当成因果关系；
- 只报告 $R^2$，不检查残差、外推风险、显著性和参数意义；
- 只报告 (p)-value，不说明效应大小和行动含义；
- 用抽样结果替代对总体、抽样框和缺失机制的检查。

## 可组合方法

可与 `optimization`、`uncertainty`、`multistage`、`prediction` 和 `inverse` 组合，形成“估计—决策—风险”完整链条。
