# 模型递进

模型递进是有证据地放宽 M0，而不是为了显得复杂而叠加算法和参数。

## 升级触发条件

只有满足下列至少一项时，从 M0 升级到 M1/M2：

- M0 对观测数据产生系统偏差；
- 题目明确加入新的现实条件；
- 参数数量级表明某个被忽略因素不可忽略；
- 目标、约束或决策阶段发生实质变化；
- M0 在边界、退化情形或可辨识性上失效；
- 参数不确定性足以改变最终结论或策略。

## 常见递进模式

- 理想条件 → 非理想修正；
- 常参数 → 时变、空变或随机参数；
- 确定性 → 随机性或区间不确定性；
- 单对象 → 多对象或网络耦合；
- 单阶段 → 多阶段状态转移；
- 平面/线性近似 → 曲面、非线性或局部模型；
- 点估计 → 置信区间、后验分布或鲁棒决策；
- 给定参数 → 由数据反演参数。

## 比较要求

递进模型至少回答：

1. M0 在哪里不足？
2. 新增因素如何进入方程？
3. 新参数如何获得，是否可辨识？
4. 复杂度增加多少？
5. 结果改善是否大于新增误差和计算成本？
6. 在什么条件下 M1 退化回 M0？

如果修正模型没有改善解释、预测、决策或稳健性，应保留更简单的模型。

## 创新优先级

优先考虑：关键量重定义、结构化简、模型推广、非理想因素修正、不确定性传播、验证设计、决策阈值和信息价值。只有真正解决计算瓶颈时，才把算法复杂化本身视为贡献。
