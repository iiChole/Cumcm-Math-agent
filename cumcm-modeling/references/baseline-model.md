# 基础模型 M0

M0 是能够回答当前问题的最小可行、可解释模型。它不是草率模型，而是后续修正、比较和验证的基准。

## 建立顺序

1. 精确描述研究对象、系统边界、相互关系以及坐标/时间口径。
2. 定义变量、参数、单位、取值域和需要求解的数学对象。
3. 写出必要假设，并说明每个假设删除了什么现实因素及其适用条件。
4. 从题面、定义、机理或概率关系逐步推导核心方程，保留关键中间关系及每步依据。
5. 明确目标、约束、初始条件、边界条件和可行域。
6. 若使用消元、降维、离散化、线性化或代表量等简化，区分精确归约与近似：前者说明等价依据，后者给出误差界、收敛依据或可检验的适用范围。
7. 判断参数是否可辨识、解是否存在以及是否可能不唯一。
8. 将最终模型集中汇总，再进入求解。

## 推导记录要求

最终公式不能替代建模论证。对影响主要结论的关系，应记录从对象与约束到最终数学表达的可复核推导链，并说明符号含义、推导依据和成立条件。

若模型包含简化或近似，还应记录：

- 完整模型与简化模型分别保留了哪些对象、变量和关系；
- 简化是严格等价、上/下界、渐近近似还是经验近似；
- 等价证明、误差界、收敛检查或其他可信度依据；
- 当完整模型可计算或可构造代表性小例时，用数值对照作为交叉核验，但不以数值吻合替代理论依据。

不影响结论的代数展开可以压缩；涉及对象定义、关键假设、目标、约束或简化有效性的步骤不能省略。

## 因素纳入标准

一个因素只有满足下列至少一项时才进入 M0：

- 题目明确要求；
- 缺少它就无法定义目标或约束；
- 它对数量级或可行性有一阶影响；
- 它是数据生成机制或物理关系不可缺少的部分。

其他因素留给后续修正，不要在第一版模型中一次加入所有现实细节。

## 先化简再求解

依次检查：

1. 是否存在解析关系、守恒或闭式表达？
2. 是否存在单调性、凸性、对称性、条件独立或支配关系？
3. 是否可以消元、降维、状态压缩或利用充分统计量？
4. 是否可以分区、分层、分阶段或拆成独立子问题？
5. 是否可以表示为图、DAG、递推或动态规划？

只有这些结构不足以解决计算瓶颈时，才考虑复杂数值搜索或启发式算法。

## 最终模型汇总

若存在目标函数、约束、状态方程或联立条件，推导后集中展示一次。例如：

```latex
\[
\boxed{
\left\{
\begin{aligned}
&\min_{\boldsymbol{x}}\quad F(\boldsymbol{x}),\\
&g_i(\boldsymbol{x})\le 0,\quad i=1,\ldots,m,\\
&h_j(\boldsymbol{x})=0,\quad j=1,\ldots,r,\\
&\boldsymbol{x}\in\Omega.
\end{aligned}
\right.
}
\]
```

统计检验、动力学、递推系统和参数估计同样需要集中说明最终数学对象。模型非常简单时可以省略盒式展示，但不能省略定义和适用条件。

## M0 完成标准

- 所有变量首次出现时已定义且单位一致；
- 关键方程有可复核的逐步推导，并可追溯到题面、定义、机理或明确假设；
- 目标和约束完整；
- 简化与近似的类型、依据、适用条件、边界和退化情形明确；
- 能产生可验证的结果；
- 后续模型能够说明相对 M0 改变了什么。
