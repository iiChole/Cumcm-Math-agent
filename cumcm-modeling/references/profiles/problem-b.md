# B 题型画像（弱先验）

本文件保留原 B 题 Skill 中的生产、抽样和决策经验，但只作为读题时的优先检查方向，不能限制方法调用。题面出现几何、微分方程、参数反演、预测或其他结构时，必须加载对应方法卡。

## 常见结构

B 题中较常见但并非必然出现：

- 有限总体抽样、次品率和质量判定；
- 成本、收益、风险和方案比较；
- 采购、生产、检测、库存或排产决策；
- 多阶段、序贯或带信息更新的决策；
- 小规模离散方案、支配关系和剪枝；
- 参数不确定性对最终决策的影响。

建议的初始标签：`statistics`、`optimization`、`discrete-optimization`、`multistage`、`uncertainty`。

## B 题优先检查项

1. 抽样分布是否与有限/无限总体和放回/不放回机制匹配？
2. 是否定义了统一的期望成本、期望收益或风险指标？
3. 统计结论是否转化为接收、拒收、采购、生产或检测规则？
4. 多阶段决策是否正确处理状态、信息顺序和后续影响？
5. 小规模离散问题是否可以枚举、支配剪枝、递推或分解？
6. 参数区间是否可能改变最优方案？
7. 最终结果是否能直接落地为具体数量、阈值和行动？

## 评分与表达偏好

- 模型先成立，再处理复杂因素；
- 分布、近似和算法必须说明适用条件；
- 表格、OC 曲线、策略阈值和方案比较有助于展示可执行性；
- 一般模型、复杂度化简和不确定性决策比单一特例更有区分度；
- 不要只报最优值，应解释决策规则和结果机制。

## 不可机械套用

- B 题不等于只能使用概率统计或生产决策；
- 出现连续机理、空间几何、时间序列或参数反演时，按结构组合 `mechanism`、`inverse`、`prediction` 或 `numerical`；
- 历年评分偏好不能替代当前题面、附件和官方要求；
- 不搜索或套用当前赛题的现成解答和优秀论文模型。
