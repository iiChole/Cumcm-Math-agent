# 论文结构与模型章节边界

本文件定义与题型无关的 CUMCM 论文结构。具体模板、当年官方要求和用户明确要求具有更高优先级。

## 默认结构

```text
题目、摘要、关键词
一、问题重述
二、问题分析
三、模型假设
四、符号说明
五、模型建立与求解
六、模型检验/灵敏度/稳健性
七、模型评价与推广
参考文献
附录
```

摘要、结果叙事和页数要求分别见 `abstract-and-narrative.md` 与 `latex-delivery.md`；用户模板和当年官方要求优先。

## 源文件组织方式

论文内容必须具有清晰的章节层级，但不要求每个一级章节都对应一个文件。按以下条件选择源文件结构：

- 完整长论文、需要反复迭代或多人协作时，采用多文件结构；
- 多文件结构至少将各顶层问题分别存储，便于局部读取、修改和审阅；
- 用户或官方模板已有组织方式时保持原结构，不为统一目录而改写模板；
- 短篇、一次性交付或单文件模板可以将正文保留在入口文件中。

没有指定模板且采用多文件结构时，默认使用中等粒度、稳定语义命名：

```text
paper/
├── main.tex
├── cumcmthesis.cls
├── references.tex
└── sections/
    ├── frontmatter.tex
    ├── problem1.tex
    ├── problem2.tex
    ├── ...
    ├── validation.tex
    ├── evaluation.tex
    └── appendix.tex
```

`frontmatter.tex` 集中存放摘要、问题重述、问题分析、模型假设和符号说明；`problemN.tex` 对应第 N 个顶层问题；`validation.tex` 汇总跨问题的独立验证、灵敏度或稳健性分析；`evaluation.tex` 存放模型评价与推广；`appendix.tex` 组织支撑材料与代码附录。局部验证也可以直接放入相应问题文件，避免重复叙述。

文件名不嵌入章节序号，正式编号由 LaTeX 生成。增减问题时只增删相应的 `problemN.tex`，不重命名验证、评价或附录文件。

采用默认多文件结构时，`main.tex` 维护导言区、题目信息、文档环境和 `\input{}` 顺序；`references.tex` 独立存放参考文献。采用其他模板时，以入口可编译、章节完整、引用可解析和内容便于维护为准。

## 各部分交付要求

- 问题重述可分为背景和题目要求；背景说明研究对象与意义，题目要求按实际问数简洁陈述。
- 问题分析按实际问题分别说明核心任务、数据或机理依据、必要处理、与前问的联系、建模动机和输出；默认不在这一部分放图。
- 模型假设逐条陈述，避免把事实、定义和结论混写为假设。
- 符号说明优先使用“符号—含义—单位”三列表格，正文中首次出现的变量仍需定义。
- “模型建立”与“模型求解”可以同节，但论证上必须区分；小标题数量服从题目实际问数，不预设一定有四问。
- 附录按官方要求组织支撑材料目录、代码和补充结果，不在正文中堆完整源代码。

## 模型章节的论证边界

每个关键模型都应让读者看清以下逻辑，但不强制使用固定的章节编号或完全相同的小节模板：

```text
研究对象与困难
→ 符号、坐标和变量
→ 假设与适用条件
→ 判定式、核心关系、目标和约束的逐步推导
→ 简化的等价依据或近似误差
→ 最终模型汇总
→ 求解方法与参数
→ 结果、解释和科学性验证
```

模型建立和模型求解可以在同一大节中，但叙事上必须区分：前者回答“为什么是这个数学模型”，后者回答“如何得到数值或策略”。不能只给最终公式，也不能用代码实现代替推导。

对影响主要结论的简化，应在正文说明简化内容、性质、成立依据和适用条件。完整模型与简化模型的数值对照可放在模型检验部分；内部调试日志不进入正文。

## 最优结果的呈现

- 正文使用建模阶段最终验证通过的结果，确保数值、图表和结论等级一致；
- 只在有全局证书时写“全局最优”，否则如实写局部最优、近似最优或当前最好可行解；
- 可以呈现有科学意义的收敛、稳健性和独立验证，但不叙述“先失败、再调参、再发现更优值”等内部排错过程；
- 若验证改变了算法或数值，必须先更新建模结果和图表，再写入论文。

## 代码与附录

- 正文不贴完整源代码；算法用数学表达、文字步骤、流程图或必要的伪代码说明；
- 完整可复现代码保存在代码目录、提交附件或代码附录中，具体位置服从当年官方要求和用户模板；
- 若使用代码附录，按功能模块组织并说明入口、输入和用途，不重复粘贴无关依赖或生成文件；
- 论文正文不出现内部报告路径、临时文件名、调试记录或工作流指令；
- 代码、运行说明和论文关键数值必须可以相互追溯。

多文件结构中的图片路径相对于当前章节文件解析；默认模板的章节文件使用 `../../figures/<name>.pdf`。单文件或其他模板按实际入口位置设置路径，不要复制同一图片来规避路径管理。
