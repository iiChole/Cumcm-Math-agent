# CUMCM 论文交付终检清单

## 内容与叙事

- [ ] 摘要首段说明背景、困难和总体思路。
- [ ] 每一问都有动机、方法、核心结果和必要验证。
- [ ] 结果段说明现象、原因和实际意义，而不是只引用图表。
- [ ] 模型评价按缺陷—影响—改进展开。
- [ ] 正文使用建模阶段最终验证通过的结果，结论等级与证据匹配。

## 图表与排版

- [ ] Overview 图展示问题、模型和信息递进，节点无重叠。
- [ ] 坐标、单位、图例和颜色语义完整。
- [ ] 最终方案有可独立阅读的总结图或表。
- [ ] 公式编号、交叉引用和章节层级正确。
- [ ] 没有 Overfull、Undefined references 或字体乱码。
- [ ] 正文页数满足用户/官方要求；默认正文 20–24 页（不含附录）。

## 可复现性与工程

- [ ] `code/` 存在且包含关键结果或图表的生成代码。
- [ ] 数据、参数、随机种子和输出可以相互追溯。
- [ ] 没有写死到开发机的绝对路径。
- [ ] README 能说明依赖和运行顺序。
- [ ] 交付包已清理缓存、临时文件和调试产物。

## 论文文件结构

- [ ] 论文入口、参考文献、类文件、图片和其他直接依赖齐全，入口能够独立编译。
- [ ] 内容章节完整，顶层问题数与问题章节数一致。
- [ ] 完整长论文在没有既定模板时至少按顶层问题拆分；短篇或已有单文件模板保持适合其任务的结构。
- [ ] 使用多文件结构时，所有 `\input{}` 都能解析到实际文件，且采用不随章节序号变化的语义文件名。
- [ ] 图片路径与实际源文件位置一致。

## 建模边界

- [ ] 建模缺陷已返回 `cumcm-modeling` 修正，而没有用排版掩盖。
- [ ] 论文没有引入未经验证的新数值、假设或最优性表述。
- [ ] 数学正确性、算法适配性和独立验证已由 `cumcm-modeling` 完成；本清单只检查交付时的一致性。
- [ ] 关键模型、数值和结论均能追溯到明确、可靠的来源材料。
