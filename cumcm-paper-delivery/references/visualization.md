# CUMCM 论文图表与视觉呈现

## 图表设计原则

每张重要图先写一句“这张图要让评委看见什么”。图表应解释机理、展示变量关系、证明模型合理、呈现方案、揭示阈值或展示误差与稳健性；无法回答明确问题的装饰性图应删除。

## Overview 图

优先展示三层信息：问题如何递进、模型如何从基础情形升级、数据/参数/结果如何传递和反馈。节点以 5–9 个为宜，箭头含义明确，数据流与模型流可用不同线型或颜色区分，避免节点重叠和箭头穿过文字。

## 图形选择

| 要表达的内容 | 优先图形 |
|---|---|
| 两变量关系 | 散点 + 拟合/理论曲线 |
| 参数敏感性 | 折线、误差带、热力图 |
| 策略切换 | 相图、分区图、阈值曲线 |
| 时间/迭代 | 折线、收敛曲线 |
| 多方案比较 | 点图或条形图 |
| 空间对象 | 等高线、热力图、曲面 |
| 路径规划 | 路径 + 约束边界 |
| 网络/状态 | DAG、状态转移图 |
| 概率分布 | 密度、CDF、区间图 |
| 模型误差 | 残差、Q-Q、箱线、误差棒 |

## 配色与表格

推荐低饱和主色：深蓝 `#3B6FB6`、青绿 `#4C9F91`、暖橙 `#D98C4A`、紫灰 `#7D789A`，风险红 `#C65A5A` 仅用于异常或超约束。全文同一语义使用同一颜色，并确保黑白打印时可由线型或标记区分。

重要表格优先使用三线表，并能脱离正文独立理解。最终结果表至少包含情形/方案、最优决策、核心目标值、约束或误差，必要时加入基准方案和次优差距；验证表可列出主模型、独立验证和相对误差。

## 高信息密度表达

- 两个参数共同决定最优方案时，优先绘制“参数平面 → 最优策略”的相图或分区图，而不是堆叠多张单参数折线。
- 比较模型与数据时，可在同一图中使用理论基础模型、观测点、修正模型和置信区间，同时表达拟合、改进与验证。
- 路径或空间方案图除最优路径外，还应标出可行域、风险或禁入区域、起终点、关键拐点和必要的局部代价。
- 多方案比较默认使用点图或条形图，谨慎使用雷达图；不使用彩虹色、荧光色、过多阴影和装饰性 3D 图。
